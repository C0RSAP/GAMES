# Аркада на одном компьютере (веб-версия)

Порт `arcade_2.py` (pygame) на HTML5 Canvas + JavaScript. Без сборки и зависимостей.

## Запуск
Открой `index.html` в браузере (Chrome, Edge, Firefox). Звук включается после первого нажатия клавиши.

## Структура
- `index.html` — страница
- `css/style.css` — стили
- `js/engine.js` — холст, ввод (физические клавиши, любая раскладка), звук, эффекты
- `js/snake.js` — Змейка (WASD и стрелки)
- `js/coins.js`, `js/pong.js` — Сбор монет и Понг+
- `js/tanks.js`, `js/sumo.js`, `js/duel.js`, `js/hangman.js` — остальные игры
- `js/wordle.js` — Wordle (5/6 букв), использованные слова хранятся в `localStorage`
- `js/main.js` — меню
- `words/` — словари (3473 слова из 5 букв, 4830 из 6 букв)

## Управление
Меню: цифры 1–8, стрелки + Enter или мышь. ESC — назад. M — звук.

## Готовность
Готово: все 8 игр — Змейка, Сбор монет, Понг+, Танки, Сумо-арена, Дуэль, Виселица, Wordle.
