# 🕹️ ARCADE — 13 Exclusive Games (2027 Edition)

**Большой сборник ретро- и неоновых аркадных игр на одном экране.**  
Играйте в одиночку, вдвоём или компанией до 4 человек на одной клавиатуре прямо в браузере!

<h3>👉 <a href="https://arcada.cfd">ЗАПУСТИТЬ АРКАДУ ОНЛАЙН (ARCADA.CFD)</a> 👈</h3>

</div>

---

## ✨ Особенности проекта

* 🚀 **Мгновенный запуск** — работает на чистом HTML5 Canvas и JavaScript без тяжелых фреймворков, сборки и внешних зависимостей.
* 👥 **Локальный мультиплеер** — режимы для 1, 2 и 4 игроков за одним компьютером.
* 🎨 **Synthwave & Neon UI** — стильная неоновая графика с плавными анимациями, частицами и адаптивным полноэкранным режимом без чёрных полос.
* 🔊 **Звуковой движок** — встроенные звуковые эффекты с быстрым отключением по одной кнопке.
* ⌨️ **Умный ввод** — управление работает на любой раскладке клавиатуры (`RU` / `EN`), а также поддерживает мышь.

## ⌨️ Управление

* **`WASD` / `Стрелки`** — навигация по главному меню и управление в играх.
* **`Enter` / `ЛКМ (Мышь)`** — выбор и запуск игры.
* **`ESC`** — выход обратно в главное меню.
* **`M`** — включить / выключить звук.
* **`F11` (или двойной клик)** — развернуть аркаду во весь экран.

## 💻 Локальный запуск

Проект не требует установки Node.js или сборщиков. Чтобы запустить аркаду на своём ПК:

1. Склонируйте репозиторий или скачайте архив:
   ```bash
   git clone https://github.com/C0RSAP/GAMES
   ```
2. Откройте файл **`index.html`** в любом современном браузере (Chrome, Edge, Firefox, Safari).
