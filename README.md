# 🎮 Аркада — 8 игр на одном экране

Коллекция из 8 мини-игр для игры с друзьями на одном компьютере.
Чистый HTML + CSS + JavaScript, без фреймворков. Идеально для GitHub Pages.

## Игры

| # | Игра | Игроки | Описание |
|---|------|--------|----------|
| 1 | 🐍 Змейка | 2 | Дуэль змеек с бонусами |
| 2 | 🪙 Сбор монет | 2–4 | Монеты, алмазы и бомбы |
| 3 | 🏓 Понг+ | 2 | Классика с бонусами |
| 4 | 🎯 Танки | 2 | Рикошеты и ящики с бонусами |
| 5 | 🤼 Сумо-арена | 2–4 | Столкни всех в воду |
| 6 | 🤠 Дуэль | 2 | Кто быстрее нажмёт |
| 7 | 🪢 Виселица | 1–2 | Угадай слово |
| 8 | 🟩 Wordle | 1 | Слова из 5 или 6 букв |

## Управление

- **Меню:** `1`–`8` выбрать игру, `Enter` играть, `M` — звук, `Esc` — выход
- **Игрок 1:** `W A S D` (+ `F` / `Space` для стрельбы)
- **Игрок 2:** `↑ ↓ ← →` (+ `Enter` для стрельбы)
- **Игрок 3:** `I J K L`
- **Игрок 4:** Numpad `8 4 5 6`

Работает при любой раскладке (русской или английской) — привязка к физическим клавишам.

## 🚀 Деплой на GitHub Pages

1. Создай новый репозиторий `arcade-web` на GitHub
2. Загрузи все файлы (`index.html`, `style.css`, `words.js`, `arcade.js`, `README.md`)
3. Зайди в **Settings → Pages**
4. Source: `Deploy from a branch` → Branch: `main` → `/ (root)`
5. Через минуту игра доступна по адресу `https://твой-ник.github.io/arcade-web/`
