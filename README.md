## 🇷🇺 Русская версия

### 🌟 О проекте

**NEON ARCADE** — браузерный сборник классических ретро-игр в синтвейв-стилистике, созданный на чистых веб-технологиях без сторонних библиотек и фреймворков. Проект поддерживает локальный мультиплеер (от 1 до 4 игроков за одной клавиатурой), неоновый UI, звуковой движок и адаптацию под русскую/английскую раскладки.

### ⌨️ Управление и запуск

* **Управление:** `WASD / Стрелки` — движение, `Enter` — старт, `ESC` — меню, `M` — звук, `F11` — весь экран.
* **Локальный запуск:** с клонированием репозитория через `git clone https://1.com` и открытием `index.html`.

## 🇬🇧 English Version

### 🌟 About The Project

**NEON ARCADE** is an in-browser retro gaming suite bathed in synthwave neon aesthetics, built with vanilla JavaScript and HTML5 Canvas with zero external dependencies. It features local couch multiplayer for 1–4 players, a native audio synthesizer, and smart keyboard layout support.

### 🎮 Game Roster

| # | Title | Genre / Highlights | Players |
| :---: | :--- | :--- | :---: |
| **01–05** | 🐍 Snake, 🪙 Coin Rush, 🏓 Pong+, 💥 Tanks, 🥋 Sumo | Action, arena and multiplayer party games | 1–4 |
| **06–10** | 🤠 Duel, 🔤 Hangman, 🟩 Wordle, 🏎 Outrun, 🐥 Flappy | Reflexes, word games, and endless runners | 1–2 |
| **11–15** | 🧱 Arkanoid, 🚀 Space Defender, 👻 Pacman, 🟦 Tetris, 🔢 2048 | Arcade classics, shooters, and tile puzzles | 1 |
| **16–20** | ☄ Asteroids, 🃏 Memory, 💣 Minesweeper, 🐸 Frogger, ⬆ Doodle Jump | Space action, logic, and platformers | 1 |

*The complete game descriptions, full control schemes, and repository file tree can be referenced directly in the primary project documentation.*

### ⌨️ Default Controls & Local Setup

* **Controls:** `WASD / Arrows` for movement, `Enter` to launch, `ESC` for menu, `M` to mute, `F11` for fullscreen.
* **Local Setup:** Clone the repository via `git clone https://github.com` and open `index.html` in your browser.
